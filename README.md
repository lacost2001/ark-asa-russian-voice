# ARK Survival Ascended — русская озвучка

Автономный установщик для Windows и полный пакет русской озвучки ASA.

**[Скачать пакет 1.0.0](https://github.com/lacost2001/ark-asa-russian-voice/releases/tag/v1.0.0)**

В пакете 1792 игровых аудиофайла и 58 кат-сцен: записки и досье, реплики HLN-A и Роквелла, истории и письма Боба, записки Lost Colony, вступления и финалы из установленной сборки. Записки без предусмотренной игрой звуковой дорожки не озвучиваются. Три ролика без диалогов и невербальные звуки сохранены.

## Установка: отдельный EXE и выбор карт

**[Скачать ASA-Russian-Voice-Setup.exe 1.2.0](https://github.com/lacost2001/ark-asa-russian-voice/releases/download/v1.2.0/ASA-Russian-Voice-Setup.exe)**

1. Скачайте только EXE и запустите.
2. Укажите папку ASA и папку загрузки. Отметьте нужные карты: рядом виден объём файлов.
3. Закройте ASA и нажмите «Скачать / установить выбранное».

Программа скачивает только выбранные карты; общие досье подключаются автоматически. Полный архив на 29 ГБ и ручное объединение частей больше не нужны. Для кат-сцен используются точные диапазоны байтов опубликованных файлов релиза 1.0.0: остальные карты не скачиваются. Звуковые контейнеры карт опубликованы отдельно в 1.2.0. Старый релиз 1.0.0 остаётся необходимым источником кат-сцен — его части нельзя удалять владельцу репозитория.

При обрыве загрузку можно продолжить. Уже скачанные файлы проверяются по SHA256, совпадающие установленные кат-сцены используются без интернета. Нужны место под выбранные файлы в кэше и дополнительное место для установки и оригинальных резервных копий на диске игры. Промежуточный ZIP не создаётся.

Карты без отдельного сюжета представлены общими досье. «Дополнительные истории Боба» — отдельный необязательный набор видео. На Genesis 2 пакет содержит звуковые реплики; объём видео зависит от того, какие сцены физически есть в проверенной сборке.

При переходе с 1.0/1.1 старый единый звуковой контейнер заменяется выбранными пакетами; его копия сохраняется в `.ASA-Russian-Voice-Backup/legacy-containers`. Чтобы сохранить полную озвучку при переходе, отметьте все карты. Уже установленные ролики других карт сохраняются. При последующих установках новые карты добавляются; снятие галочки ничего не удаляет. «Вернуть все оригиналы» восстанавливает все файлы, записанные в журнал установки.

Версия установщика 1.2.0, содержимое озвучки прежнее. Само приложение автоматически не обновляется. Все установочные файлы проверены; воспроизведение новых отдельных контейнеров по картам ещё требует проверки в игре.

## Совместимость и проверка

Проверенная исходная сборка ASA: **25691765**. Это пакет для **ASA, не Survival Evolved**. Неизвестные версии заменяемых файлов блокируются, чтобы не перезаписать их без проверенного оригинала.

Все файлы проверены по SHA256; 58 видео проверены по кадрам и извлечённому звуку. Три сцены The Island подтверждены пользователем в игре. Остальные новые сцены пока требуют игровой проверки. Музыка и эффекты сохранены с разделением исходной дорожки; возможны артефакты разделения. Настройки и сохранения сервера не меняются.

Установщик поддерживает независимый выбор карт.

## Исходники установщика

Репозиторий содержит установщик и его проверки. Большие готовые файлы находятся в Releases, а не в Git. API-ключи и локальные рабочие материалы не включены.

Python 3.11+:

```powershell
python test_installer.py
python test_download.py
python test_maps.py
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --onefile --windowed --name ASA-Russian-Voice-Setup --add-data "maps.json;." asa_installer.py
```

Собранный EXE работает отдельно и сам скачивает пакет. Если рядом уже есть `manifest.json` и файлы пакета, используется локальная копия. Для запуска исходника можно указать пакет явно:

```powershell
python asa_installer.py --package "D:\ASA-Russian-Voice"
```
